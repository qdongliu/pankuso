## 它是什么

**盘库搜（pankuso.com）** 是一个专注于“找到东西”的网盘资源搜索入口。它不生产资源，也不存储文件，只做一件事：把你输入的关键词，扔进全网公开的网盘索引里，然后把还活着的链接捞回来，干干净净地摆在你面前。


### 目前盘库搜在做的事

- **多源聚合**：一次输入，同时检索百度、夸克、阿里云盘等主流网盘的公开索引，不用你挨个平台翻。
- **死链过滤**：优先展示有效链接，减少“点进去发现资源没了”的挫败感。
- **界面克制**：没有弹窗、没有强制跳转、没有伪装成下载按钮的广告位。
- **即搜即走**：不需要注册账号，不需要关注公众号，输入关键词，拿到结果，完事。

### 🕷️ 高性能爬虫架构
网盘搜索的核心在于“抓取”与“清洗”。我们搭建了高效的分布式爬虫系统，能够全天候高频抓取全网公开分享的网盘资源。这保证了我们的资源库**更新极快、覆盖面极广**，很多冷门资源别人搜不到，在盘库搜却能精准命中。
